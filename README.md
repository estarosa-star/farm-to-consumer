# Farm-to-Consumer

A modern marketplace app that connects local farms directly with end users. This MVP lets customers browse fresh produce, discover nearby farms, and support local agriculture.

## Features

- Browse farm products by category
- View featured farms and fresh seasonal picks
- See farm location, rating, and delivery info
- Responsive marketplace layout for web and mobile
- Clean, trust-focused design for direct-to-consumer commerce

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Tech stack

- Next.js
- TypeScript
- Tailwind CSS-ready styling
